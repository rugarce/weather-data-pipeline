# Weather Data Pipeline

End-to-end data engineering project that ingests weather data from a public API, validates and transforms it, and stores it in PostgreSQL.

## Tech Stack

- Python
- PostgreSQL
- Docker
- SQL
- pytest
- GitHub Actions
